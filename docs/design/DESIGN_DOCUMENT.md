## 2. User Roles & Access Mapping

| Page             | Route               | Who can access it                                              |
|-------------------|---------------------|------------------------------------------------------------------|
| Login / Sign up  | `/login`            | Anyone (unauthenticated)                                         |
| My Data          | `/user`             | Any logged-in user — manages **their own** metric entries        |
| My Jira Assignments | `/jira-assignments` | Any logged-in user — their own Jira-derived counts             |
| Jira Authentication | `/jira-auth`      | Any logged-in user — connect a personal Jira API token           |
| Manager Dashboard | `/dashboard`        | Managers — view reportees' entries, Jira metrics & calculator     |
| Admin Panel       | `/admin`            | Single hard-coded admin email only (`ADMIN_EMAIL` in `app.py`)   |
| Reset Password    | `/reset-password`   | Anyone with a valid, time-limited reset link                     |

Manager-to-reportee mapping is driven by the `manager_email` field captured at sign-up
(`storage.py` / `models.py`) — a reportee automatically appears in their manager's
**"View Team Member"** dropdown on the dashboard.

## 7. Flow 5 — Weightage Calculator (floating widget)

A floating 🧮 chat-bubble icon (bottom-right of the dashboard) opens a **non-blocking,
resizable** panel so managers can keep working with Manual Entries while it's open.

- Selecting a team member **auto-selects the matching Role** (SDET / Lead Engineer) and
  **pre-fills "Actual" values** from that employee's real metric totals.
- Manager can override any value, then click **Calculate** to see a per-metric score
  (`min(actual/target, 1) × weightage` for positive weightage, uncapped for penalty/negative
  weightage rows) and a **Total Weighted Score**.
- Panel edges (top, left, and top-left corner) are draggable, PowerPoint-style, to resize;
  closing the panel resets it back to its default size.

![Weightage Calculator](screenshots/08-manager-weightage-calculator.png)

## 11. Notes on Metric-to-Weightage Mapping

The Weightage Calculator's targets/weightages mirror the org scorecard:

| Metric field                      | SDET target / weight | Lead Engineer target / weight |
|-----------------------------------|-----------------------|--------------------------------|
| `user_stories_completed`          | 40 / 45%              | 45 / 35%                       |
| `valid_defects`                   | 80 / 18%              | 95 / 13%                       |
| `invalid_defects`                 | 5 / -2%               | 3 / -2%                        |
| `volunteer_opportunities`         | 5 / 5%                | — (Lead Eng. uses "Initiatives Proposed", manual entry only) |
| `p0_defects_leaked`                | 2 / -15%              | 1 / -25%                       |
| `complex_stories`                  | 12 / 10%              | 12 / 10%                       |
| `demo_opportunities`               | 12 / 5%               | 20 / 5%                        |

Negative weightages act as penalties — their score contribution is uncapped (more
defects/leaks reduce the total further), while positive weightages cap credit at 100%
of target.
